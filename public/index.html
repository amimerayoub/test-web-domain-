API Reference

01 — Bulk Domain Check

Check up to 100 names × 10 TLDs per request. Uses Verisign's official bulk-check API.

cURL 
curl "https://your-app.vercel.app/api/bulk-check?names=Datafyno,Nexavo&tlds=com,io,ai"
JavaScript
const res  = await fetch('/api/bulk-check', {
  method : 'POST',
  headers: { 'Content-Type': 'application/json' },
  body   : JSON.stringify({ names: ['Datafyno','Nexavo'], tlds: ['com','io','ai'] })
});
const data = await res.json();
data.results.available.forEach(d => console.log(`✅ ${d.domain} → ${d.register_url}`));
ParamTypeRequiredDescription
namesstring/arrayrequiredComma-separated names (no TLD needed). Max 100.
tldsstring/arrayoptionalTLDs to check. Default: com. Max 10.
include-registeredbooloptionalInclude taken domains. Default: true

02 — Domain Age (RDAP)

Returns age, registration date, expiry, registrar, nameservers, DNSSEC status. No API key required.

cURL
curl "https://your-app.vercel.app/api/domain-age?domain=admin.com"
Response (key fields)
{
  "age": { "years": 31, "months": 5, "days": 15, "total_days": 11475, "category": "Mature" },
  "dates": { "registered_human": "November 17, 1994", "expiration_human": "November 16, 2031" },
  "expiry": { "days_remaining": 2038, "status": "active" },
  "registrar": { "name": "Amazon Registrar, Inc.", "iana_id": "468" },
  "nameservers": ["NS-89.AWSDNS-11.COM", ...],
  "dnssec": { "signed": false }
}
ParamTypeRequiredDescription
domainstringrequiredDomain to look up. Auto-strips https:// and www.

03 — Brand Name Check

Checks one brand name across 28 domain extensions + 31 social media platforms in parallel.

cURL
curl "https://your-app.vercel.app/api/check?q=mybrand&type=all"
ParamTypeRequiredDescription
qstringrequiredBrand name to check (min 2 chars)
typestringoptionalall | domains | social. Default: all
tldsstringoptionalCustom TLD list. Default: all 28
